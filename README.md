# ShopPro - Quản Lý Bán Hàng Thông Minh 🛒

Ứng dụng bán hàng web với QR/Barcode Scanner và Google Sheets.

## Tính năng

- 📱 **Quét mã QR/Barcode** từ điện thoại
- 📊 **Google Sheets** làm database
- 🛒 **POS bán hàng** với giỏ hàng
- 📈 **Dashboard** thống kê doanh thu

## Cài đặt

1. Clone repo này
2. Mở `apps-script/Code.gs` → Copy vào [Google Apps Script](https://script.google.com)
3. Chạy hàm `setupSpreadsheet()` → Deploy thành Web App
4. Cập nhật URL trong `js/config.js`
5. Mở `index.html` hoặc host trên GitHub Pages
